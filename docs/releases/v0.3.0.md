# Finrod v0.3.0

Finrod is now a **personal assistant that runs on a home server**. One Node
service keeps the conversation and does the research. The phone opens it as a
web app over the tailnet. The v0.2.0 browser product is retired.

## Included

- One continuous stream with streamed answers and Markdown, one divider per day, and search, that any tailnet device can reopen.
- Restart safety: every message and answer part is saved before it appears. An answer cut off by a restart shows as interrupted.
- Web research through Exa, with the sources collapsed into one line under each answer.
- Images, PDFs, and text files in a message, up to 20 MB each. PDF pages without a text layer are named in the message.
- Thumbs up or down on each answer.
- Memory that you approve, edit, or delete. Only approved memories reach the model.
- Voice input by holding the send button, transcribed on the server with faster-whisper while you speak; the audio is deleted afterwards.
- A queue for messages sent while an answer runs.
- Home-screen install on the iPhone.
- Release archives with checksums, a systemd user service, and a daily update check that rolls back if the new release does not answer.

## Known limits

- Voice needs `FINROD_TRANSCRIBE_COMMAND`. Recording and the keyboard are not yet verified on an iPhone.
- No way yet to forget a single message.
- One profile per server.
- Chats, files, and memories are not encrypted on the server's disk.
- Two end-to-end tests cover chat and restart safety. The phone checks are done by hand.

See [Operations](../OPERATIONS.md) for installing and updating the server.
